Antigravity ＋ Remotion 自動動画制作システム指示文
（完全自動／字幕対応／Remotionブラウザプレビュー強制版・再プレビュー抑制対応）
============================================================
■ システムの目的
フォルダ内の素材を使用し、以下を完全自動で実行すること。

1. MP3＋画像 → base_video.mp4 を生成
2. 完了報告
3. 字幕使用の確認
4. OK時、Remotion を自動生成・起動
5. フォルダ内の .txt / .lrc ファイルに含まれるタイムスタンプをそのまま使用して字幕合成
6. 字幕を「画面最下部」に「大きく」配置した final_with_subtitles.mp4 を生成
7. 【最重要】Remotion を起動した状態で、「現在ユーザーが使用中の Chrome ブラウザ」に新しいタブを1つだけ開いてプレビューを自動表示（※自動再生は禁止）
   ※ただし、同一セッション内で複数回修正・再生成が行われている場合は、新しいプレビュー画面（タブ）は開かない
============================================================
■ 0. フォルダ内の前提素材
- music.mp3
- images（1枚以上、背景用）
- (※歌詞テキストファイルは、この時点では無くても良い。後からチャットで受け取り作成する)
【字幕ファイルに関する絶対条件】
- タイムスタンプは自動生成・補正せず、ファイル内容をそのまま使用すること。
============================================================
■ 0.5. 【自動化オプション】LRC歌詞の自動生成（Gemini API）
- フォルダ内に `music.mp3` があり、`.lrc` (字幕ファイル) が**ない**場合、以下の手順で自動生成を行う。
- **対話ルール（重要）**:
  ユーザーから動画作成依頼があった際、LRCファイルがない場合は必ず以下のように尋ねること。
  「精度の高いタイムスタンプを作成するため、**『ひらがなの歌詞』**と**『漢字の歌詞』**の両方を教えてください（テキストファイルの配置、またはチャットへの貼り付けをお願いします）。」
- **実行フロー**:
  1. 提供された歌詞をそれぞれ `lyrics_hiragana.txt` (ひらがな)、`lyrics.txt` (漢字) として保存する（ファイル名がない場合）。
  2. 自動化スクリプト `create_lrc.py` を、ひらがな歌詞指定オプション付きで実行する。
     コマンド例: `python3 create_lrc.py music.mp3 lyrics.txt --hiragana_path lyrics_hiragana.txt`
  3. これにより、AIは「ひらがな歌詞」を正解として音声を聞き取り（Step 1）、その後「漢字歌詞」に置換する（Step 2）フローを自動実行し、高精度な `.lrc` を生成する。
- **必須条件**: 環境変数 `GOOGLE_API_KEY` の設定（AI Studioと同じ無料枠のキーでOK）。

============================================================
■ 1. Antigravity：MB4（base_video.mp4）生成
- mp3＋画像を合成。出力：base_video.mp4（1920×1080）。
- 完了後、ユーザーに通知し自動で字幕確認フローへ進む。
============================================================
■ 2. 字幕合成の実行確認（必須）
- MB4 完成後、必ず「字幕を合成しますか？」と質問すること。
============================================================
■ 3. Remotion プロジェクト自動生成
- Remotion プロジェクトを自動生成し、base_video.mp4 を /public にコピー。
- 【環境変数の適用】
  package.json の scripts を生成する際、プレビュー用のコマンドには必ず BROWSER=none を付与すること。
  例: "start": "BROWSER=none remotion preview ..."
============================================================
■ 4. 字幕テキストの取り扱い（厳守）
- タイムスタンプの計算・変換・補正は一切禁止。ファイル記載のまま使用。
============================================================
■ 5. Remotion：字幕付き動画生成（レイアウト・視認性設定）
【字幕の表示位置】
- 字幕は必ず「画面の最下部」に配置すること。被写体の位置に関わらず、テロップとしての安定性を優先する。
【字幕のサイズとスタイル】
- スマホ視聴でもはっきりと読めるよう、意図的に「大きめのフォントサイズ」に設定すること。
- 背景なし。
- 可読性を確保するため、文字には必ず「太めの縁取り（ストローク）」または「強いドロップシャドウ」を付与し、背景画像に埋もれないようにすること。
- フォントは視認性の高いゴシック体（またはそれに準ずるフォント）を使用。
============================================================
■ 5-2. 演出エフェクトの取り扱い（重要）
- 曲のイメージに合う場合のみ、控えめなフェードやスケール変化を許可。
- 迷った場合は「何もしない」を選択。派手な演出は禁止。
============================================================
■ 6. 書き出し
- 出力：final_with_subtitles.mp4（H.264 / 1920×1080）。
============================================================
■ 7. 【最重要】完成後の自動プレビュー動作（Chrome二重起動防止・強制指定）
final_with_subtitles.mp4 生成完了後、必ず以下を自動実行すること。

【絶対遵守事項：二重起動の完全抑制】
1. 環境変数の強制使用:
   Remotion の preview サーバーを起動する際は、必ず BROWSER=none を付与し、Remotion自体がブラウザを開こうとする動作を完全に抑制すること。
2. ブラウザの限定:
   AIエージェント用のChromeは絶対に使用せず、ユーザーが現在操作している「通常のChromeブラウザ」を検出して使用すること。
3. 正しい初回プレビュー動作:
   - BROWSER=none remotion preview でサーバー起動。
   - ユーザーのChromeに「新しいタブ」を1つだけ開き、プレビューURLを表示。
   - 自動再生はせず、静止状態で待機。
4. 再生成・修正時の追加ルール:
   - すでにプレビュータブが存在する場合は、新しいタブを開かない。タブの増殖・強制リロードを禁止。
============================================================
